## 1. 目的

本アプリケーション（以下「本アプリ」）は、Ryze Tello ドローンを Android 端末から Wi-Fi（UDP）経由で制御するための操作アプリケーションである。

本アプリは、以下のことを可能にする。

- Tello への接続・切断
- 映像ストリームの受信（ライブビュー表示）
- 映像の録画（生 H.264 NAL データの保存）
- 飛行制御（離陸・着陸・移動・回転・停止）
- 移動距離・回転角・速度のパラメータ設定
- バッテリー残量の監視
- コマンドの音声発声（Tello への送信を行わない発声モード）
- 録画ファイルの一覧表示・削除・エクスポート（MP4 変換含む）

## 2. 対象範囲

### 2.1 対象

- Ryze Tello 単体との通信・制御
- Android 端末上での操作 UI
- 映像ストリームの受信・表示・録画
- 録画ファイルの管理・エクスポート

### 2.2 対象外

- Tello 以外のドローン・機器との互換
- iOS 等の Android 以外のプラットフォーム
- 複数 Tello 同時制御
- 自動飛行・経路計画・障害物回避
- 音声認識による操作（発声は TTS による出力のみ）

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| Tello | Ryze 社製の小型ドローン。UDP によるコマンド制御と映像ストリーム送信に対応する。 |
| コマンド | Tello に送信するテキスト形式の制御命令（例: `takeoff`, `forward 50`）。 |
| コマンドポート | コマンド送信に使用する UDP ポート（既定 `8889`）。 |
| ステータスポート | Tello からステータスを通知される UDP ポート（既定 `8890`）。 |
| 映像ストリーム | Tello が送信する H.264 映像データ（既定ポート `11111`）。 |
| NAL ユニット | H.264 映像データの最小単位。開始コード（`00 00 00 01` / `00 00 01`）で区切られる。 |
| ライブビュー | 映像ストリームをリアルタイムにデコードして表示する機能。 |
| 録画 | 受信した映像データをファイルに保存する機能。 |
| WatchDog | 接続中に周期的にコマンドを送信し、接続維持・バッテリー監視を行う機能。 |
| 発声モード | コマンドを Tello に送信せず、音声（TTS）で読み上げるモード。 |
| エクスポート | 録画ファイルを端末の共有領域（MediaStore）へ書き出す処理。 |

## 5. 機能仕様

### F-01 接続管理

| 項目 | 仕様 |
|---|---|
| 機能 | Tello への接続・切断を行う。 |
| 操作 | メイン画面の「接続 / 切断」ボタン。 |
| 送信コマンド | `command` |
| 状態表示 | 接続中 / 未接続 / 発声モード をアイコンとテキストで表示。 |
| 制約 | Tello と同一 Wi-Fi 環境であること。 |

### F-02 映像ストリーム

| 項目 | 仕様 |
|---|---|
| 機能 | 映像ストリームの受信開始・停止、ライブビュー表示。 |
| 操作 | メイン画面の映像ボタン。 |
| 送信コマンド | `streamon` / `streamoff` |
| 表示 | 受信中はライブビュー、未受信時は Tello ロゴ画像を表示。 |
| 前提 | 接続中であること。 |

### F-03 映像録画

| 項目 | 仕様 |
|---|---|
| 機能 | 受信映像をファイルに録画する。 |
| 操作 | メイン画面の録画ボタン（開始 / 停止）。 |
| 保存形式 | 生 H.264 NAL データ（`.h264` 拡張子、Annex-B で保存）。 |
| ファイル名 | `M` + `yyyyMMdd_HHmmss` + `_0.h264` |
| 保存先 | アプリ外部ストレージ `getExternalFilesDir()/TelloMove/` |
| 前提 | 接続中かつ映像ストリーム受信中であること。 |

### F-04 飛行制御

| 項目 | 仕様 |
|---|---|
| 機能 | Tello の飛行を制御する。 |
| 操作 | メイン画面の制御パッド。 |
| 送信コマンド | `takeoff` / `land` / `forward <距離>` / `back <距離>` / `left <距離>` / `right <距離>` / `up <距離>` / `down <距離>` / `cw <角度>` / `ccw <角度>` / `stop` |
| 前提 | 接続中であること。 |

#### 制御パッドの配置

```
        [上]
  [左]  [前]  [右]
        [下]
  [CCW] [離陸] [CW]
        [着陸]
```

> 注: 実際の画面では、離陸・着陸・前後左右・上下・CW/CCW・停止の各ボタンが 3 行のグリッドとして配置される。

### F-05 パラメータ設定

| パラメータ | 単位 | 範囲 | 既定値 | 送信コマンド |
|---|---|---|---|---|
| 移動距離 | cm | 20 – 500 | 50 | `forward/back/left/right/up/down <距離>` |
| 回転角 | 度 | 1 – 360 | 90 | `cw/ccw <角度>` |
| 速度 | cm/s | 10 – 100 | 20 | `speed <速度>` |

- 範囲外の値は、入力時に範囲内にクランプされる。
- 速度は「設定」ボタンで `speed <速度>` を送信する。

### F-06 バッテリー監視

| 項目 | 仕様 |
|---|---|
| 機能 | バッテリー残量（%）を取得して表示する。 |
| 方式 | WatchDog が接続中に周期的に `battery?` を送信し、応答から残量を取得。 |
| 送信間隔 | 12 秒 |
| 表示 | バッテリーアイコン（残量に応じた 10 段階） |
| 切替 | 設定画面で WatchDog の有効/無効を切替可能（既定: 有効）。 |

### F-07 発声モード

| 項目 | 仕様 |
|---|---|
| 機能 | コマンドを Tello に送信せず、音声（TTS）で読み上げる。 |
| 切替 | 設定画面で有効/無効を切替可能（既定: 無効）。 |
| 言語 | 日本語（`Locale.JAPAN`）。 |
| 制約 | 日本語 TTS が利用可能なこと。有効時はコマンドは送信されない。 |

#### 発声キーワード対応表

| コマンド | 発声 |
|---|---|
| `streamon` | 録画終了 |
| `streamoff` | 録画開始 |
| `rec_start` | 録画開始 |
| `rec_stop` | 録画終了 |
| `takeoff` | 離陸 |
| `land` | 着陸 |
| `command` | コマンド |
| `emergency` | 緊急 |
| `stop` | バージョン |
| `up/down/left/right/forward/back/cw/ccw <値>` | 値に応じた方向・程度（例: `forward 50` → 「すこし前」/「まえ」） |

> 注: 発声キーワードの対応は実装上の既定であり、一部のコマンド（`streamon`/`streamoff`）は発声内容が直感と逆になる点に注意。

### F-08 ファイル管理

| 項目 | 仕様 |
|---|---|
| 機能 | 録画ファイルの一覧表示・削除・エクスポート。 |
| 一覧 | `getExternalFilesDir()/TelloMove/` 配下のファイル一覧。 |
| 全削除 | 全ファイルを削除（確認ダイアログあり）。 |
| 単体削除 | 選択ファイルを削除（確認ダイアログあり）。 |
| 生データエクスポート | 選択ファイルを MediaStore（`Movies/TelloMove/`）へ書き出す。 |
| MP4 変換エクスポート | 生 NAL データを MP4 へ変換して MediaStore へ書き出す。 |

### F-09 設定

| 項目 | 仕様 |
|---|---|
| Wi-Fi 設定 | 端末の Wi-Fi 設定画面を開く。 |
| WatchDog 切替 | 周期的コマンド送信の有効/無効（既定: 有効）。再起動後に有効化。 |
| 発声モード切替 | コマンド発声の有効/無効（既定: 無効）。 |
| 録画ファイル一覧 | 録画ファイル一覧画面へ遷移。 |
| 操作説明 | 操作説明書（GitHub）を開く。 |
| プライバシーポリシー | プライバシーポリシー（GitHub）を開く。 |

### F-10 権限管理

| 権限 | 用途 |
|---|---|
| `INTERNET` | ネットワーク通信 |
| `ACCESS_NETWORK_STATE` | ネットワーク状態の確認 |
| `ACCESS_WIFI_STATE` | Wi-Fi 状態の確認 |
| `CHANGE_WIFI_MULTICAST_STATE` | マルチキャスト通信 |
| `VIBRATE` | 振動 |

- 起動時に必要な権限を要求する。
- 権限が拒否された場合は、アプリを起動できない（終了する）。

| 項目 | 要件 |
|---|---|
| 対応 OS | Android 7.0 (API 24) 以降 |
| 画面方向 | 縦長（`max_aspect` 指定） |
| 画面常時表示 | 有効（`FLAG_KEEP_SCREEN_ON`） |
| 権限 | 起動時に要求、拒否時は終了 |
| ネットワーク | Tello と同一 Wi-Fi 環境 |
| 言語 | 日本語（UI・発声） |

## 7. 利用環境・前提条件

- Ryze Tello が起動済みであること。
- Android 端末と Tello が同一 Wi-Fi（Tello が提供するアクセスポイント等）に接続されていること。
- Tello の IP アドレスが既定 `192.168.10.1` であること（既定値）。
- 発声モードを使用する場合、日本語 TTS が利用可能であること。

## 8. 制約事項

- 本アプリは Tello 単体との通信を前提とする。
- 映像録画は生 H.264 NAL データであり、再生には MP4 変換（本アプリ内変換または外部ツール）が必要。
- 発声モード有効時は、コマンドは Tello に送信されない。
- WatchDog の設定変更は、アプリ再起動後に有効となる。
