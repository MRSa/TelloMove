# TelloMove 注意事項

| 項目 | 内容 |
|---|---|
| アプリ名 | TelloMove |
| バージョン | 1.0.2 |
| 文書版 | 1.0 |
| 更新日 | 2026-11-01 |

> 本ドキュメントは、TelloMove の利用上・開発上の注意・制約・既知の挙動をまとめる。

---

## 1. 安全上の注意

- **飛行中の危険**：Tello はプロペラを回転させる飛行体です。周囲に人・動物・障害物がないことを確認のうえ操作してください。
- **視界の確保**：ライブビューに頼りすぎず、常に Tello の位置を視認してください。
- **バッテリー残量**：残量が少ない状態で離陸・飛行を続けると、急降下・墜落の恐れがあります。バッテリーアイコンを常に確認してください。
- **緊急停止**：異常が確認された場合は速やかに「停止」ボタン（`stop`）または着陸（`land`）を行ってください。
- **責任**：本アプリの使用に伴う一切の事故・損害について、開発者は責任を負いません。自己責任でご利用ください。

## 2. 通信の制約

- **同一 Wi-Fi 必須**：Android 端末と Tello は同一 Wi-Fi 環境（Tello が提供するアクセスポイント等）に接続されている必要があります。
- **IP アドレス**：Tello の IP は既定 `192.168.10.1` です。環境により異なる場合は、`CommandPublisher` の `ipAddress` を変更する必要があります。
- **UDP の信頼性**：UDP はパケットの到着を保証しません。コマンド送信は 1500ms のタイムアウトで応答を待ち、タイムアウト時は失敗として扱われます。
- **応答判定**：コマンドの成功判定は応答文字列に `ok` を含むかどうかで行います。
- **接続状態**：接続状態はコマンド応答・ステータス受信に基づいて更新されます。Wi-Fi の不安定さにより接続が切れることがあります。

## 3. 映像・録画について

- **録画形式**：録画ファイルは**生 H.264 NAL データ**（`.h264` 拡張子、Annex-B）です。そのままでは一般的なプレイヤーで再生できない場合があります。
- **MP4 変換**：再生・共有には MP4 変換が必要です。本アプリの「MP4 ファイルエクスポート」または外部ツール（ffmpeg 等）で変換してください。
- **保存先**：録画ファイルは `getExternalFilesDir()/TelloMove/` に保存されます。
- **エクスポート先**：エクスポートは MediaStore の `Movies/TelloMove/` に書き出されます。
- **録画の前提**：録画は「接続中」かつ「映像ストリーム受信中」の場合のみ可能です。
- **ファイル名**：`M` + `yyyyMMdd_HHmmss` + `_0.h264` の形式です。

## 4. 権限について

- **起動時の権限要求**：アプリ起動時に `INTERNET` / `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` / `CHANGE_WIFI_MULTICAST_STATE` / `VIBRATE` を要求します。
- **拒否時の挙動**：権限が拒否された場合、アプリは起動を中止（`finish()`）します。再度起動時に権限を付与してください。
- **`ACCESS_MEDIA_LOCATION`**：API 29 未満の端末では権限チェックから除外されます。

## 5. 発声モードについて

- **送信されない**：発声モード有効時は、コマンドは Tello に**送信されません**。音声（TTS）で読み上げるだけです。
- **日本語 TTS 必須**：日本語（`Locale.JAPAN`）の TTS が利用可能な必要があります。利用できない場合は発声できません。
- **発声内容の注意**：一部のコマンドは発声内容が直感と逆になる場合があります（例: `streamon` → 「録画終了」、`streamoff` → 「録画開始」）。
- **用途**：発声モードは、Tello への実際の操作を行わずに操作練習・確認を行う用途を想定しています。

## 6. 設定の反映タイミング

- **WatchDog**：設定画面での WatchDog 有効/無効の切替は、**アプリ再起動後に有効**となります。
- **発声モード**：発声モードの切替は即時に反映されます。

## 7. 既知の制約・未実装機能

- **無効化されているボタン**：制御パッド・設定画面には、現在無効化（`enabled = false`）されているボタンが複数存在します。これらは未実装・予約のボタンです。
- **複数 Tello 対応なし**：本アプリは Tello 単体との通信を前提としています。
- **自動飛行なし**：経路計画・自動飛行・障害物回避は対応していません。
- **iOS 非対応**：Android 専用です。
- **MP4 変換の実装**：`NALToMP4Converter2` を使用します。

## 8. 開発上の注意

- **シングルトン参照**：通信系コンポーネントは `AppSingleton` の companion object 経由で参照します（`AppSingleton.publisher` 等）。
- **スレッド安全**：UDP 受信・映像デコード・コマンド送信は独立スレッドで動作します。UI 更新は必ず `Dispatchers.Main` で行います。
- **例外処理**：各処理は `try-catch` で例外を捕捉し `printStackTrace()` でログ出力しています。本番環境ではログの扱いに注意してください。
- **定数の変更**：ポート・タイムアウト・バッファサイズ等は各クラスの companion object に定義されています。変更時は通信の安定性に影響するため注意してください。

## 9. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 接続できない | Tello と同一 Wi-Fi であること、Tello が起動中であることを確認。Wi-Fi 設定を確認。 |
| 映像が表示されない | 接続中か、映像ストリームが ON であるかを確認。 |
| コマンドが応答しない | Wi-Fi の安定性、Tello のバッテリー残量を確認。 |
| 録画ファイルが再生できない | MP4 変換エクスポートを行う、または ffmpeg 等で変換する。 |
| 発声されない | 日本語 TTS が利用可能か、発声モードが有効かを確認。 |
| バッテリーが表示されない | WatchDog が有効か、接続中かを確認。 |
